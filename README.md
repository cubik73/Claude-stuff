# Claude-stuff

Stuff for Claude: mods and plugins for Claude Code.

## Mods

| Mod | What it does |
| --- | --- |
| [Prompt Master](mods/prompt-master/) | Rewrites your rough prompt into a clearer, more specific one before you send it. One click on the **✨ Prompt Master** button above the prompt box, or `/prompt-master`; **Undo** restores your draft. |

Install any mod from this repository's marketplace, at the prompt of a Claude Code terminal session:

```
/plugin install prompt-master --marketplace cubik73/Claude-stuff
```

See each mod's README for details.
